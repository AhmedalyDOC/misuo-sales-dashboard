
# MISUO Sales Dashboard | Excel

An interactive sales dashboard built in Microsoft Excel to analyze sales performance, customer behavior, product trends, and delivery operations for MISUO Furniture.

The project transforms raw sales data into meaningful insights through data cleaning, KPI analysis, PivotTables, PivotCharts, and interactive dashboard features.

![MISUO Sales Dashboard](Sales%20Dashboard%20Preview.png)

---

## Project Overview

This project focuses on analyzing sales data for an Egyptian furniture company, MISUO, with the goal of providing a clear overview of sales performance and operational efficiency.

The dashboard enables users to monitor key business metrics, identify top-performing products and sales platforms, analyze customer segments, explore geographic sales distribution, and evaluate delivery performance.

---

## Data Cleaning & Preparation

Before building the dashboard, the raw dataset required several cleaning and transformation steps:

- Identified and handled missing values.
- Extracted city names from customer addresses into a separate column.
- Classified customers into **Person** and **Company** segments.
- Organized and prepared the dataset for analysis and reporting.

These steps helped improve data quality and make the dataset more suitable for business analysis.

---

## Key Performance Indicators (KPIs)

The dashboard provides an overview of business performance through the following metrics:

- **Total Sales** – Total revenue generated.
- **Total Orders** – Number of orders.
- **Average Selling Price** – Average selling price across sales.
- **Customer Segmentation** – Comparison between individual and company customers.
- **On-Time Delivery Rate** – Percentage of orders delivered on time.

## Sales Analysis

The dashboard includes visualizations to explore different aspects of sales performance:

### Product Analysis
- Best-selling product.
- Most popular color.
- Product sales performance.

### Sales Platform Analysis
- Sales distribution across platforms.
- Identification of the platform generating the highest sales.

### Geographic Analysis

### Customer Analysis
- Individual customers (**Person**) vs. corporate customers (**Company**).

## Delivery Performance

Delivery performance was one of the key areas investigated in this project.

The dashboard tracks:

- On-Time Delivery Rate.
- Late deliveries.
- Delivery status breakdown.

Order statuses include:

- Completed
- Cancelled
- Not Delivered
- Rejected
- Returned

The analysis highlighted delivery delays as an operational area that requires attention and improvement.

---

## Interactive Features

To make the dashboard more flexible and user-friendly, I implemented:

- Interactive **Slicers** to filter data.
- Dynamic dashboard updates based on filter selections.
- A **Reset Filters** button built using VBA.
- One-click filter reset to return the dashboard to its default view.

These features allow users to explore the data without manually interacting with the underlying tables.

---

## Dashboard Objectives

The main objectives of this dashboard are to:

- Monitor overall sales performance.
- Identify best-selling products and popular colors.
- Evaluate sales performance across different platforms.
- Understand customer segmentation.
- Analyze sales distribution across cities and areas.
- Monitor delivery performance and identify delays.
- Support data-driven business decisions.
